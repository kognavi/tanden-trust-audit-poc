# Cost Guardrails

## Goal

This portfolio is a proof of concept, not an always-on production service.

The default operating goal is:

> **Local-first development, AWS only on demand, and no always-on AWS resources.**

A successful portfolio outcome is a reproducible demonstration of:

`AI Agent event → Evidence → Sign → Store → Verify → Tamper Detection`

It is not continuous hosting.

## Default Rule

Normal development and CI must not require real AWS API calls.

Default paths should use:

- synthetic fixtures
- local ECDSA
- fake/in-memory AWS SDK clients
- local or Docker PostgreSQL
- local verification
- GitHub Actions without AWS credentials

## AWS Usage Rule

Real AWS calls are allowed only for an explicit, manual demonstration.

The repository provides a manually dispatched workflow:

`.github/workflows/aws-integration.yml`

It requires an explicit `RUN` confirmation before AWS credentials are requested.

## Prohibited by Default

Do not introduce these into the portfolio baseline without explicit human approval:

- NAT Gateway
- persistent Amazon RDS / Aurora
- persistent ECS/Fargate services
- Amazon OpenSearch Service
- provisioned model throughput
- always-on EC2 instances
- automatically scheduled real-AWS integration tests
- PR or push workflows that make billable AWS calls
- broad IAM permissions for convenience

## Allowed On-Demand Components

For a short validation run, these are acceptable when needed:

- Amazon Bedrock / AgentCore invocation
- AWS KMS signing
- small Amazon S3 writes
- CloudWatch logs generated by the demo
- short-lived resources that are deleted after validation

## Evidence of Validation

Instead of keeping cloud resources running, preserve proof of the successful demo under `docs/demo/` or an equivalent review packet.

Record only non-sensitive information such as:

- execution date
- AWS Region
- services used
- Evidence ID
- safe KMS key reference
- digest
- verification result
- tamper-test result
- cleanup result

Never commit credentials, raw secrets, private keys, or unnecessary PII.

## CI Policy

Default CI:

- runs local/unit tests
- validates sample evidence
- validates AI Agent evidence
- performs no AWS credential exchange
- performs no real AWS API calls

Real AWS integration:

- manual only
- time-bounded
- explicit confirmation required
- cleanup required after the run

## Cost Review

Any change that creates recurring AWS spend or a new always-on resource requires human approval before merge.
