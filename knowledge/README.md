# Repository Knowledge Vault

このdirectoryはAI Development OSの永続状態です。

- `00-inbox/`: 未整理の思考、仮説、調査メモ
- `10-decisions/`: ADR補助、設計判断、判断変更の理由
- `20-research/`: 外部調査、比較、検証メモ
- `30-learnings/`: 実装・障害・reviewから得た再利用可能な学び
- `90-archive/`: 現在の判断には使わない履歴
- `templates/`: note template

原則として過去noteを黙って上書きせず、関係性をfrontmatterで追加します。
